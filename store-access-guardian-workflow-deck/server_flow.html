Store API / server-confirmed access

The server decides what can be used.

A preview can explain an item. Only the server can make the final access decision.

01 / Catalog

Published

The item is available in the catalog rather than draft or archived.

Otherwise: hidden
02 / Guardian

Approved

The authored source passed provenance, attribution, privacy, and suitability review.

Otherwise: blocked
03 / Coin

Balance checked

The server validates price, account balance, and the spend transaction.

Otherwise: no charge
04 / History

Access checked

An existing active record is returned instead of charging a duplicate request.

Otherwise: create once
Result / account access

Approved use

The server records which customization the account may use. Authorship remains unchanged.

Invariant: client previews never approve content, alter provenance, or grant access on their own.
