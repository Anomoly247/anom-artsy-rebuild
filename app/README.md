# AO Sanctuary React Application

This directory contains the verified React, tRPC, Express, Drizzle, and Manus OAuth application added alongside the repository's existing static HTML site. The root-level static files remain unchanged.

## Development

From this directory, install dependencies with `pnpm install --frozen-lockfile`, then start the development server with `pnpm dev`.

## Validation

The application can be checked with `pnpm check`, tested with `pnpm test`, and bundled with `pnpm build`.

## Dashboard styling

The current dashboard hierarchy uses cyan (`#00ffff`) as the primary neon accent, restrained magenta as a secondary highlight, gold for progression and milestone elements, and a deep-black base background. The dashboard balance label is displayed as **Glow Points** with the **GP** unit.
